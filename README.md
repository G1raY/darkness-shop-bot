# Darkness Shop Bot

Telegram-бот для продажи цифровых товаров ("cookies"), разложенных по категориям: баланс пользователя, оплата криптовалютой через CryptoBot, ручная и по расписанию загрузка стока администратором, история заказов, рассылки.

## Стек

`pyTelegramBotAPI` (telebot, синхронный), CryptoBot API (`pay.crypt.bot`) для приёма платежей, товары и профили пользователей хранятся в файлах (JSON/каталоги), без внешней БД.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить токены
python DarknessBot.py
```

- `BOT_TOKEN` — токен бота от @BotFather
- `CRYPTO_PAY_TOKEN` — API-токен CryptoBot (@CryptoBot → Crypto Pay → Create App)
- `ADMIN_IDS` — Telegram ID администраторов через запятую

## Структура

- `DarknessBot.py` — вся логика бота: каталог, корзина, баланс, оплата, админ-панель, рассылки
- `Cookies/` / `AutoCookies/` — папки со стоком товаров (создаются локально, не хранятся в репозитории)
- `Users/` — профили и история покупок пользователей (не хранится в репозитории)

## Известные ограничения

- Хранение состояния в плоских файлах вместо БД — подходит для небольшого магазина, не рассчитано на высокую нагрузку.
- Один файл на всю логику бота (роутинг, хранение и бизнес-логика вперемешку) — рефакторинг на модули был бы следующим логичным шагом.
